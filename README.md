# doit 📝

A highly customizable, feature rich, TUI Based, "to do app" to organize your life.

### FEATURES AND GOALS 😏

- Highly Customizable
- Terminal User Interface (TUI) Based.
- Future plan to expand it to android (using JAVA)
- Reminders
- Trackers
- Dashboards
- Monthly, weekly, yearly report and reward systems
- Goal setter (long term , short term)
- A separate goal progress system for daily tracking of routine habits that need to be repeated daily ( so the user don't have to make to do lists daily- they just make one panel and it will track everything )
- Master database
- and many many more features to come along.
